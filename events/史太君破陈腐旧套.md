# 史太君破陈腐旧套

## 事件经过

元宵夜宴中，女先儿要说《凤求鸾》一类才子佳人故事，[[02_Learn/08_book-wikis/红楼梦/characters/贾母.md|贾母]]听了开头便指出这些故事“都是一个套子”。她不只是嫌故事老套，更批评这类书把世宦书礼人家写成私情乱礼，既不懂大家规矩，也不合现实人情。

“史太君破陈腐旧套”因此是一段文学评论，也是一段家族伦理判断。贾母用老辣经验拆穿通俗套路，说明她并非只会享乐的老封君，而是熟知礼法、人情和叙事俗套的人。

## 叙事功能

这段话让贾母的“见过世面”具体化。她不是抽象维护礼教，而是从家族生活经验出发，指出俗书对大家闺秀、父母规矩和婚姻秩序的误写。

同时，这段也可看作《红楼梦》对普通才子佳人叙事的自我区分：同样写男女之情，《红楼梦》不愿把情写成简单私奔和巧合团圆，而要写情如何被家族、礼法、身份和命运层层制约。

## 阅读抓手

- 看贾母批评的对象：不是“有情”本身，而是廉价套路。
- 看她的判断来源：她用大家族真实规矩反驳俗套故事。
- 看小说的自我定位：《红楼梦》借贾母之口，和普通才子佳人书拉开距离。

- 这段也是读者理解《红楼梦》为何不同于才子佳人小说的入口。
