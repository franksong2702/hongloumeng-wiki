# 迎春之死

## 事件经过

[[02_Learn/08_book-wikis/红楼梦/characters/贾迎春.md|迎春]]被[[02_Learn/08_book-wikis/红楼梦/characters/贾赦.md|贾赦]]许配给[[02_Learn/08_book-wikis/红楼梦/characters/孙绍祖.md|孙绍祖]]后，婚后饱受虐待。第080回，她回娘家哭诉孙绍祖好色、好赌、酗酒，还以贾赦收过五千两银子为由羞辱她。

第109回，迎春含泪辞别众人，说自己“没有再来的时候了”。不久，孙家传来病重消息，最终“结褵年余”便被孙家揉搓致死，丧事也因贾母病重而草草完结。

## 叙事功能

迎春之死是“婚姻制度吃人”的最直白呈现。宝黛钗婚姻线还有情感与礼法的复杂包裹；迎春线几乎没有遮蔽：父亲收银许婚，丈夫暴虐，娘家同情但无力救援。

她的死也说明贾府体面已经空心化。一个贵族小姐回娘家哭诉，众人都落泪，却没有人能把她真正留下。

## 事件层次

| 层次 | 读法 |

| 交易层 | 贾赦收银、许婚，迎春被折算成债务关系。 |
| 受辱层 | 孙绍祖以五千两羞辱迎春。 |
| 求援层 | 迎春回娘家诉苦，但只能得到劝慰。 |
| 诀别层 | 第109回辞别时，迎春已经知道自己无路可回。 |
| 死亡层 | 孙家不善医治，贾府也无力追究。 |

## 阅读抓手

- **不要只责备迎春懦弱**：懦弱是性格弱点，但不是制度暴力的根源。
- **注意贾赦的位置**：父亲的决定比迎春自己的意愿更有权力。
- **注意王夫人的无力**：她能落泪，能劝慰，却不能救迎春。
- **和迎春误嫁并读**：误嫁是原因链，之死是结果链。
- **和探春远嫁对读**：一个近嫁而死，一个远嫁难归，四春各有制度性命运。
