# 甄士隐出家

## 事件说明

甄士隐出家发生在第001回后半段。女儿英莲被拐、葫芦庙失火、家业败尽之后，甄士隐投奔岳父封肃，却又遭遇冷淡与盘剥，贫病交加。就在他人生退无可退时，跛足道人唱《好了歌》，甄士隐听后悟出《好了歌解》，随道人飘然而去。

这个事件不是单纯的“看破红尘”。它先把甄士隐推到世俗生活的尽头，再让他通过佛道语言完成转身。也因此，甄士隐成了全书第一个真正退出红尘的人。

## 事件层次

1. [[02_Learn/08_book-wikis/红楼梦/events/英莲被拐.md|英莲被拐]]使甄家先失去血脉希望。
2. [[02_Learn/08_book-wikis/红楼梦/events/葫芦庙失火.md|葫芦庙失火]]又把甄家的现实家业烧尽。
3. 投奔封肃后的冷遇，让甄士隐彻底看见世态炎凉。
4. 《好了歌》把这些遭遇解释为功名、金银、娇妻、儿孙皆不可恃。
5. 甄士隐作解并离家，完成从入世受苦到出世觉悟的转折。

## 叙事功能

甄士隐出家是全书的第一重“出世”样本。它在故事刚开始时就把终局提前展示出来：家业、亲情、功名都可能转眼成空，真正理解这一点的人会从红尘中退场。

它也和后文[[02_Learn/08_book-wikis/红楼梦/events/宝玉中举出家.md|宝玉中举出家]]形成遥远照应。甄士隐是开篇的“先觉者”，宝玉则是经历完整红楼梦之后的“后觉者”。

## 阅读抓手

- 甄士隐不是突然厌世，而是被一连串失落推到觉悟边缘。
- 《好了歌解》不要只当诗看，它是甄士隐对自己经历的总结。
- 这个事件也解释了“甄士隐”这个名字：真事隐去，假语村言随后登场。
- 读这里时可以和[[02_Learn/08_book-wikis/红楼梦/events/石头入世.md|石头入世]]对读：一个入世，一个出世。
