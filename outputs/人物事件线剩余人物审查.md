# 人物事件线剩余人物审查

## 这份文档解决什么问题

这份审查不是继续“补人物线”，而是给人物线建立边界：哪些人物已经有主要事件线，哪些人物暂时不该补，哪些人物后续应通过漏链审查、事件补建或结构改造处理。

核心原则：**不要为了覆盖率制造伪时间线。** 一个只有单一事件节点的人物，不适合硬加 `## 主要事件线`；这类人物更适合保留事件页反链，或以后另设轻量的 `## 相关事件`。

## 后续维护闸门

以后任何人物线新增或修改，都应满足以下规则：

1. `## 主要事件线` 必须至少有 2 个有效事件节点；单节点人物默认不加。
2. P0/P1 人物可写完整线或短线；P2/P3 人物不因覆盖率压力强行补线。
3. 人物线中的每个事件链接，事件页必须反链该人物。
4. 事件页反链只补人物线实际引用所需，不借机全库扩张。
5. 红学人物和神话原型不走普通小说人物事件线。
6. 每次批量补线后运行：
   - `python3 scripts/character_event_line_review.py`
   - `python3 scripts/character_event_reverse_link_check.py`
   - `python3 scripts/wiki_health_check.py --strict --output /tmp/hongloumeng_health.md --limit 20`

`--strict-current` 只用于复核本次 Phase 4D 快照：覆盖脚本为 105 / 58 / 19 / 28，反链脚本为 58 / 359 / 0。未来若有意新增人物线，应先用普通模式查看新分布，再按新状态更新治理文档。


## 人物线反链检查脚本

脚本位置：[[02_Learn/08_book-wikis/红楼梦/scripts/character_event_reverse_link_check.py]]

用途：

- 扫描所有已有 `## 主要事件线` 的人物页。
- 抽取人物线中的事件链接。
- 检查事件页是否存在。
- 检查事件页是否反链该人物。

推荐命令：

```bash
python3 scripts/character_event_reverse_link_check.py --json-output /tmp/hongloumeng_character_event_reverse_link_check.json
```
